# نمایش فشرده گالری و دکمه‌های تب‌های ترم

این تغییر فقط برای وب است. داده، مجوز و پروژه Flutter تغییر نمی‌کنند.

## رفتار

- گزینه‌های «نمایش فشرده» و «نمایش با توضیحات» از گالری حذف می‌شوند. کارت‌های زیرصفحه‌های گالری همیشه فشرده‌اند؛ انتخاب قبلی مرورگر برای حالت توضیح‌دار روی کارت‌ها اثر ندارد. توضیحات کامل در نمایش جزئیات و ویرایش باقی می‌مانند.
- در تب مدیریت ترم، افزودن ترم، تعریف ترم‌های استاد و خروجی‌های ترم نمایش داده می‌شوند. افزودن تخفیف فقط در تب تخفیف‌ها دیده می‌شود؛ دکمه‌های ترم و خروجی‌های آن در تب تخفیف پنهان‌اند.
- نوار ابزار مشترک، گروه دکمه‌های هر تب را یکجا منتقل می‌کند تا مخفی‌بودن گروه حفظ شود. تابع فعلی جابه‌جایی تب، محتوای تب و گروه دکمه‌هایش را هم‌زمان به‌روز می‌کند. خود دکمه‌ها و رویدادهایشان حفظ می‌شوند.
- دکمه «تعریف ترم‌های استاد» با آیکن لیست به‌همراه «+»، در همان اندازه ۴۴×۴۴ دکمه افزودن و رنگ تم نمایش داده می‌شود. نام کامل عمل برای دسترس‌پذیری و هاور باقی است.

## فایل‌ها و انتشار

فایل‌های اجرایی این مرحله:

1. `assets/Analytics/js/terms.js`
2. `assets/Analytics/js/admin.js`
3. `Modules/Analytics/Resources/Views/layouts/admin.php`
4. `Modules/Analytics/Resources/Views/sections/terms.php`
5. `Modules/Analytics/Resources/Views/sections/term-discounts.php`
6. `assets/Analytics/js/gallery.js`
7. `assets/Analytics/js/gallery-templates.js`

انتشار اتمی ترجیح دارد. در انتقال مرحله‌ای، ابتدا `terms.js` و `admin.js` و سپس قالب‌ها حاضر باشند؛ JavaScript جدید با قالب قبلی نیز کار می‌کند. دو فایل گالری با نسخه قبلی دیگری سازگارند. نسخه‌بندی فعلی JavaScript با hash محتوا حفظ می‌شود. checksum فایل‌ها در `docs/panel-assets-upload.sha256` ثبت می‌شود. کلاس، وابستگی، endpoint یا migration جدید لازم نیست. اگر تغییرات قبلی پنل هنوز منتشر نشده‌اند، این فایل‌ها باید همراه بسته مربوط به آن تغییرات منتقل شوند.

برای بازگشت، ابتدا دو قالب ترم و سپس فایل‌های JavaScript و چیدمان همین مرحله بازیابی شوند؛ دو فایل گالری نیز به نسخه قبلی یکسان برگردند. داده، تصاویر و تنظیمات واقعی سرور پاک یا اصلاح نشوند.

پس از آپلود، چهار بخش گالری را با مرورگری که قبلاً حالت توضیح‌دار داشت باز کنید و نبود گزینه‌ها و فشرده‌بودن کارت‌ها را ببینید. سپس چند بار بین مدیریت ترم و تخفیف‌ها جابه‌جا شوید؛ فقط دکمه‌های همان تب باید دیده شوند. آیکن لیست‌به‌علاوه، توضیح هاور و بازشدن فرم تعریف ترم‌های استاد را در فارسی/انگلیسی و موبایل/دسکتاپ بررسی کنید. آزمون‌های محلی، تأیید انتشار روی سرور اصلی نیستند.

## اعتبارسنجی

- `term_toolbar_browser_test.cjs`: قالب واقعی ترم و JavaScript و CSS مشترک در چهار حالت فارسی/انگلیسی و عرض ۳۹۰/۱۲۸۰؛ نمایش دکمه‌های مختص هر تب، جابه‌جایی و چینش مجدد، نبود دکمه تکراری، حفظ خود دکمه و رویداد، اندازه و نام دسترس‌پذیر آیکن جدید موفق بود. دو حالت نوار ابزار بازبینی تصویری شدند.
- `gallery_overview_browser_test.cjs`: نمای اصلی و چهار زیرصفحه، تنظیم قدیمی detailed، نبود کنترل‌های تغییر نمایش، فشرده‌ماندن کارت با فراخوانی قدیمی، حفظ توضیحات در جزئیات و فرم ثبت رسانه موفق بود.
- آزمون‌های قبلی `term_discounts_browser_test.cjs`، `term_batch_browser_test.cjs`، `panel_add_icons_browser_test.cjs` و `panel_introductions_browser_test.cjs` دوباره موفق شدند. آزمون‌ها از داده ساختگی و پاسخ‌های محلی استفاده می‌کنند و داده سرور اصلی را تغییر نمی‌دهند.
- syntax فایل‌های JavaScript و PHP و whitespace موفق بود. دو آزمون گالری و نوار ابزار ترم به فهرست اجرای کامل اضافه شدند؛ اجرای کامل انتشار صرفاً برای این اصلاح ظاهری تکرار نشد.
