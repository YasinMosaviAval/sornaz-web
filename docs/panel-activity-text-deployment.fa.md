# متن اعلان‌ها و نمایش امتیازها

2. `core/database/DatabaseChangeNotifier.php`

جدول امتیازهای شخصی از حالت صفحه‌بندی خود قالب مشترک استفاده می‌کند: هر صفحه ۱۰ ردیف و کنترل‌های اول، قبلی، شماره صفحه، بعدی و آخر. نوار کنترل برای جدول خالی یا حداکثر ۱۰ ردیف مخفی است. ردیف‌ها در صفحات بعدی از ۱۱، ۲۱ و ... ادامه پیدا می‌کنند. فقط مقدارهای نمایشی مجاز در داده صفحه‌بندی قرار می‌گیرند. آزمون `node scripts/personal_points_pagination_browser_test.cjs` حالت‌های صفر، ۱۰، ۱۱ و ۲۳ ردیف را بررسی می‌کند.

برای این قابلیت، ابتدا JavaScript مشترک، سپس قالب مشترک و در پایان `my-points.php` را منتشر کنید؛ برای بازگشت همین سه فایل را به نسخه قبلی برگردانید و کش را تازه کنید. migration لازم نیست. قالب‌های دیگر بدون گزینه صفحه‌بندی، رفتار فعلی خود را حفظ می‌کنند.

ابتدا کلاس جدید، سپس سرویس‌ها، JavaScript و قالب‌ها را در یک انتشار هماهنگ قرار دهید. تغییر شمار ستون‌های جدول امتیازها به نسخه جدید قالب و JavaScript نیاز دارد؛ کش مرورگر/CDN را تازه کنید. از انتشار قالب جدید با JavaScript کش‌شده قبلی خودداری کنید. PSR-4 موجود کلاس جدید را بارگذاری می‌کند؛ در نصب دارای classmap authoritative، autoload را با Composer از همین نسخه بازسازی کنید. migration یا کتابخانه جدید لازم نیست.

اعلان جدید به جای نام جدول و فیلد، رویداد واقعی را توصیف می‌کند. تخفیف درصدی با مقدار ثبت‌شده در همان رویداد نمایش داده می‌شود. اعلان‌های فنی قدیمی فقط هنگام خواندن به متن عمومی همان رویداد تبدیل می‌شوند؛ چون مقدار تاریخی تخفیف در آن‌ها ذخیره نشده، مقدار فعلی رکورد جایگزین مقدار تاریخی نمی‌شود. متن اعلان دستی حفظ می‌شود. گیرنده، محدوده داده و روند امتیازدهی تغییر نمی‌کنند.

ثبت اعلان دستی در رابط فقط برای مدیر سایت نمایش داده می‌شود؛ این تغییر، مجوزهای موجود API ارسال اعلان را تغییر نمی‌دهد. ستون «فرستنده» از کاربر ارسال‌کننده خوانده می‌شود و در نبود آن «سیستم» است. جدول امتیازهای شخصی از قالب عمومی استفاده می‌کند، ردیف دارد و ستون‌های فنی حذف شده‌اند. اطلاعات شخصی همچنان فقط برای کاربر واردشده خوانده می‌شوند.

## آزمون و بازگشت

آزمون‌های `node scripts/panel_activity_text_test.cjs`، `node scripts/points_stability_browser_test.cjs` و `node scripts/panel_inbox_browser_test.cjs` متن دوزبانه، حفظ اعلان دستی، جداسازی گیرنده، rollback، ستون‌های مدیر/کاربر و قالب مشترک را بررسی می‌کنند. fixtureها مستقل از دیتابیس اصلی هستند.

پس از انتشار روی محیط تست، تخفیف ۲ درصدی آزمایشی ایجاد و متن اعلان فارسی و انگلیسی را بررسی کنید. کاربر دیگر نباید اعلان گیرنده اول را ببیند. عنوان صفحه پیام‌ها و امتیازها، نام فرستنده، نبود دکمه ثبت اعلان برای کاربر عادی و هم‌ترازی ستون‌های امتیاز را بررسی کنید. آزمون یا انتشار سرور اصلی توسط این تغییر انجام نشده است.

برای بازگشت، هفت فایل موجود را به نسخه قبل برگردانید و کش را تازه کنید؛ کلاس جدید را تا پایان درخواست‌های در حال اجرا نگه دارید. نیازی به تغییر یا بازیابی داده نیست. اعلان‌های جدید ذخیره‌شده متن خوانای خود را حفظ می‌کنند.
