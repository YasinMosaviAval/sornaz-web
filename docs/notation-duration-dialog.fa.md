# دیالوگ انتخاب کشش نت و سکوت — ۷ نوامبر ۲۰۲۶

رفتار جدید اپ در وب نیز اعمال شد: لمس کوتاه پیانو یا علامت سکوت، منبع را با رنگ تم هایلایت می‌کند و شبکهٔ کشش‌ها را بدون عنوان دیداری یا دکمهٔ انصراف باز می‌کند. انتخاب کشش نت را ثبت می‌کند؛ لمس بیرون، Escape یا Back بدون ثبت هایلایت را پاک می‌کند. این رفتار برای نمادهای سکوت پنل وب نیز برقرار است. ورود نت، مالکیت، ذخیره‌سازی، Undo/Redo و ساختار داده از مسیرهای موجود استفاده می‌کنند.

بخش «میزان و تکرار» و میان‌بر ابزار میزان از دیالوگ ابزار نت حذف شدند؛ دکمهٔ مستقل ابزار میزان حفظ شده است. عنوان فیلدهای هر دسته بالای منوی آن‌ها قرار گرفته است. پیش‌نیازهای قبلی Bravura، پیانوی مشترک و کنترل‌های نمادین لازم‌اند.

## انتشار و بازگشت

فقط دو فایل runtime این مرحله لازم‌اند: ابتدا `assets/notation/notation.css`، سپس `assets/notation/notation.js`. CSS با رفتار قدیمی سازگار است؛ بارگذاری مرحله‌ای آن دادهٔ نت را تغییر نمی‌دهد. قرارداد API، کلاس PHP، migration یا وابستگی تازه‌ای نداریم. نسخه‌بندی فایل‌ها از مسیر فعلی صفحه پیروی می‌کند. برای بازگشت، همین دو فایل را به نسخهٔ سازگار قبلی برگردانید؛ دیتابیس و دادهٔ نت دست‌نخورده می‌مانند.

پس از انتقال به سرور تست، در عرض موبایل و دسکتاپ نت یا سکوت را انتخاب کنید؛ پیش از تعیین کشش چیزی نباید ثبت شود. لمس بیرون باید هایلایت را بردارد. کشش نقطه‌دار را ثبت، ذخیره و بازگشایی کنید؛ دیز و بمل و Undo/Redo را بررسی کنید. بخش حذف‌شده نباید در ابزار نت ظاهر شود و عنوان فیلدها باید بالای منو باشد. مسیر رد ویرایش نت خصوصی توسط کاربر دیگر نیز از قرارداد قبلی بررسی شود.

آزمون‌های مرتبط با فایل‌های واقعی وب در فارسی/انگلیسی، روشن/تاریک و عرض‌های ۳۹۰/۱۲۸۰ اجرا می‌شوند. گزارش‌های محلی در `storage/logs/duration-dialog-{shared,controls,layout,parity}.log` و گزارش تعامل واقعی در پروژهٔ اپ نگهداری می‌شوند. انتشار روی سرور اصلی و آزمون روی دستگاه فیزیکی انجام نشده است.

نتیجه: هشت اجرای تعامل واقعی با فایل‌های وب و هشت اجرای معادل اپ موفق‌اند؛ آزمون‌های shared features، کنترل‌های نمادین در هر دو زبان/عرض، چیدمان پنل و ذخیره/بازگشایی آفلاین وب موفق‌اند. چهار بررسی تصویری قبلی واحد ضرب و پیانو با فایل‌های وب نیز موفق ماندند. نحو JavaScript و `git diff --check` موفق‌اند. آزمون کامل انتشار مرحلهٔ قبل برای این اصلاح محدود تکرار نشده است.
