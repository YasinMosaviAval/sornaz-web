# تب‌های امتیازها و وضعیت قوانین

فایل‌های این تغییر به ترتیب انتشار:

1. `Modules/Analytics/Resources/Views/sections/panel-page-tabs.php`
2. `assets/Analytics/js/points.js`
3. `Modules/Analytics/Resources/Views/sections/points.php`

قالب مشترک تب‌ها یک handler اختیاری برای تب‌های داخلی دارد؛ سایر صفحات همچنان از `showSection` استفاده می‌کنند. تب پیش‌فرض امتیازها «امتیازهای من» است و دو موجودی و جدول امتیازهای کسب‌شده را نشان می‌دهد. شمار قوانین فعال، فیلترها، افزودن قانون و جدول قوانین در تب «قوانین امتیازها» هستند. تب‌ها در جریان عادی صفحه قرار دارند.

وضعیت قانون ستون جداگانه مدیر سایت است. کاربر عادی وضعیت و فیلتر آن را نمی‌بیند. دکمه وضعیت برای مدیر سبز/قرمز است، تغییر را از API موجود ثبت و نتیجه را دوباره دریافت می‌کند. درخواست تکراری حین ثبت مسدود و خطای ثبت نمایش داده می‌شود. مجوز سرور تغییر نکرده است. تغییر دیتابیس یا وابستگی جدیدی لازم نیست.

فایل JavaScript جدید را پیش از قالب صفحه منتشر و کش مرورگر/CDN را تازه کنید. این سه فایل باید هماهنگ باشند؛ برای بازگشت نسخه قبلی هر سه را قرار دهید و کش را تازه کنید. آزمون `node scripts/points_stability_browser_test.cjs` تب پیش‌فرض، جابه‌جایی، مخفی بودن وضعیت کاربر، تغییر فعال/غیرفعال مدیر و رنگ دکمه‌ها را بررسی می‌کند. صفحه‌بندی امتیازهای شخصی نیز با `node scripts/personal_points_pagination_browser_test.cjs` آزموده می‌شود.

پس از آپلود روی محیط تست، با مدیر وضعیت یک قانون آزمایشی را تغییر و بازگردانید؛ با کاربر عادی نبود کنترل وضعیت را بررسی کنید. هر دو حساب باید با تب امتیازهای من وارد شوند. یک صفحه دیگر دارای تب، مانند درس‌ها، را نیز بررسی کنید. انتشار و آزمون سرور اصلی انجام نشده است.
