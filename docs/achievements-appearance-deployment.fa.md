# سوابق، نظرسنجی و تنظیمات ظاهر

منوی «سوابق و دستاوردها» برای همهٔ کاربران واردشده در دسترس است و در جایگاه بعد از سازمان قرار می‌گیرد. اگر کاربر مجوز منوی سازمان نداشته باشد، این منو مستقل نمایش داده می‌شود. ترتیب تب‌ها: تحصیلات، گواهی‌ها، پاداش‌ها و جوایز، سوابق کاری، رویدادها، آثار منتشر شده، نشان‌ها. صفحهٔ نخست این منو تحصیلات است. نظرسنجی‌ها تب سوابق نیستند و منوی مستقلی بعد از امور مالی دارند.

کنترلر و API موجود سوابق برای کاربران واردشده باز شده‌اند؛ سرویس محدودهٔ خواندن و نوشتن را تعیین می‌کند. کاربر عادی فقط سوابق خودش را می‌بیند. آموزشگاه به شعبه‌های خودش دسترسی دارد، شعبه فقط به خودش و مدیر دارای چند عضویت فقط به محدودهٔ همان عضویت دسترسی دارد. عضویت غیرفعال مجوز نیست. شناسهٔ کاربر مقصد از فرم بدون کنترل سرور پذیرفته نمی‌شود. مدیر سایت می‌تواند برای کاربران عادی نیز نشان اعطا کند؛ سایر کاربران در بخش نشان‌ها فقط مشاهده دارند. ایجاد، ویرایش، حذف و تغییر وضعیت نشان در سرویس و قرارداد API موبایل به مدیر سایت محدود شده است. نام نشان در `badge_title` پاسخ API نیز برگردانده می‌شود. رأی نظرسنجی در محدودهٔ مجاز و زیر قفل و تراکنش ثبت می‌شود.

چهار منوی سوابق، نظرسنجی‌ها، تحلیل رفتار و تعطیلات رسمی از رنگ استاندارد متن سایدبار در حالت روشن/تاریک استفاده می‌کنند. گزینهٔ رنگی `original` با عنوان «اصلی» اضافه شده است: رنگ اصلی روشن `#0064FB` و تیره `#C19E32`، مطابق `ColorPalette.original` در Flutter. گزینه‌های قبلی و انتخاب ذخیره‌شدهٔ کاربران حفظ می‌شوند؛ تم پیش‌فرض وب خودکار عوض نشده است.

وزن قلم و گردی گوشه‌ها در فرم تنظیمات شخصی API ارائه نمی‌شوند و ارسال مستقیم آن‌ها توسط غیرمدیر با 403 رد می‌شود. تنظیمات عمومی مدیر سایت باقی است. در هر دو شاخهٔ Flutter، همین دو کنترل در تنظیمات عمومی اپ برای غیرمدیر حذف شده‌اند و فرم پنل تنظیمات شخصی نیز آن‌ها را از قراردادهای قدیمی حذف می‌کند. مقادیر پیشین کاربران از پایگاه داده پاک نشده‌اند.

## فایل‌های انتشار

این تغییر migration، کلاس جدید یا وابستگی جدید ندارد. فایل‌های اجرایی این مجموعه:

- `Modules/Analytics/Controllers/Web/AdminProfileContentController.php`
- `Modules/Analytics/Controllers/Web/PersonalPanelDataController.php`
- `Modules/Analytics/Services/AdminProfileContentService.php`
- `Modules/Analytics/Services/AdminSettingService.php`
- `Modules/Analytics/Services/MobilePanelCatalog.php`
- `Modules/Analytics/Services/MobilePanelNavigation.php`
- `Modules/Analytics/Routes/routes.php`
- `Modules/Analytics/Resources/Views/admin-panel.php`

- `Modules/Analytics/Resources/Views/sections/sidebar.php`
- `Modules/Analytics/Resources/Views/sections/achievement-page-tabs.php`

- `assets/theme/theme.css`
- `assets/theme/theme.js`

انتشار مرحله‌ای: ابتدا سرویس و کنترلرهای دارای کنترل مجوز و مسیرهای سازگار را منتقل کنید؛ سپس قراردادهای پنل موبایل، فایل‌های CSS/JavaScript و در پایان قالب‌ها را منتشر کنید. CSS و JavaScript پیش از قالب مصرف‌کننده حاضر باشند. پس از آماده‌شدن API، تغییرات همین قابلیت در هر دو شاخهٔ Flutter قابل استفاده‌اند. قراردادهای پیشین حذف نشده‌اند و داده‌ها مهاجرت یا پاک نمی‌شوند.

بازگشت: ابتدا قالب‌ها و رابط کلاینت را برگردانید. کنترل سمت سرورِ اعطای نشان و محدودهٔ سازمان را حفظ کنید؛ برگرداندن آن کنترل‌ها می‌تواند مجوز وسیع‌تر نسخهٔ قدیمی را دوباره فعال کند. داده‌ها و نشان‌های ثبت‌شده حذف نشوند. لازم نیست تنظیم ذخیره‌شدهٔ `original` را پاک کنید؛ برای بازگشت کامل ظاهر، پیش از حذف پشتیبانی این گزینه، با مدیر یک تم قبلی انتخاب شود.

## بررسی پس از آپلود روی سرور تست

با کاربر عادی، آموزشگاه، شعبه و مدیر سایت وارد شوید. ترتیب منوها و هفت تب را در فارسی/انگلیسی بررسی کنید؛ نظرسنجی‌ها تب داخلی نداشته باشند. آموزشگاه فقط شعبه‌های خودش را ببیند؛ شعبه به دادهٔ آموزشگاه یا شعبهٔ خواهر دسترسی نداشته باشد. درخواست مستقیم اعطای نشان توسط غیرمدیر و ذخیرهٔ وزن قلم/گردی گوشه با 403 رد شود. مدیر برای یک کاربر آزمایشی نشان ثبت کند و همان کاربر نام درست نشان را ببیند. تم اصلی را در هر دو حالت روشن/تاریک انتخاب، ذخیره و پس از بازکردن مجدد بررسی کنید.

آزمون‌های خودکار از SQLite، دادهٔ ساختگی و مرورگر محلی استفاده می‌کنند؛ آزمون MySQL هاست یا انتشار روی سرور اصلی انجام نشده است. اسکریپت‌های اختصاصی: `achievements_access_test.cjs`، `achievements_browser_test.cjs`، `appearance_permissions_browser_test.cjs` و `personal_panel_api_test.php`. فهرست سایر تغییرات ثبت‌نشدهٔ فایل‌های جلسه در `session-files-deployment.fa.md` جدا ثبت شده است.
