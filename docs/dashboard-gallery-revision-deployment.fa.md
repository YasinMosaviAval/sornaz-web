# تغییر چیدمان داشبورد و حساب کاربری

فایل‌های قابل آپلود:

- `Modules/Analytics/Resources/Views/sections/dashboard.php`
- `Modules/Analytics/Resources/Views/sections/account.php`
- `assets/Analytics/js/dashboard-templates.js`
- `assets/Analytics/js/account.js`

کارت‌های آماری داشبورد چهار مورد هستند. شش کارت اطلاعاتی به ترتیب کلاس‌های
امروز، غیبت‌های امروز، ثبت‌نام‌های اخیر، تعطیلات و مرخصی‌های نزدیک، آخرین
پرداخت‌ها و آخرین واریزها نمایش داده می‌شوند. هشدارها و اقدامات نیازمند بررسی
حفظ شده‌اند. دکمهٔ به‌روزرسانی دستی حذف شده و رفتار به‌روزرسانی موجود باقی است.
عنوان حساب کاربری پسوند نوع حساب ندارد و توضیح در سمت مقابل عنوان قرار دارد.

کلاس، وابستگی، قرارداد API و migration جدیدی وجود ندارد. قالب‌ها و JavaScript
به هر ترتیب با نسخهٔ قبلی سازگارند؛ فایل‌های ثابت تازه باید با روش معمول
ابطال کش پروژه در دسترس قرار بگیرند. بازگشت با جایگزینی همین چهار فایل با
نسخهٔ قبلی انجام می‌شود و تغییری در داده‌ها لازم نیست.

آزمون‌های مرتبط: `scripts/dashboard_layout_test.php` و
`scripts/dashboard_cards_revision_test.cjs`. بعد از آپلود، با حساب آزمایشی مجاز
ترتیب کارت‌ها، چهار آمار، فیلتر شعبه‌ها و عنوان/توضیح حساب کاربری را بررسی کنید؛
دسترسی بدون نشست به endpoint داشبورد باید همچنان رد شود.

تغییر گالری Flutter مستقل از انتشار این فایل‌ها است؛ از endpointها و مجوزهای
فعلی استفاده می‌کند و به OMR یا تحلیل عملکرد آزمایشی وابستگی ندارد.
