# همگام‌سازی پیانوی نت‌نویسی با تیونر — ۷ نوامبر ۲۰۲۶

پیانوی دو بخش اپ از ویجت مشترک Flutter استفاده می‌کند. رندر مرورگر مستقل وب/دسکتاپ مقادیر رنگ و اندازه را از `assets/notation/piano_style.js` می‌خواند؛ این فایل خروجی `PianoKeyboardSpec` در پروژهٔ Flutter است. آن را دستی ویرایش نکنید. پس از تغییر منبع از `tools/sync_piano_keyboard.dart` در اپ استفاده کنید و حالت `--check` را برای خروجی هر دو پروژه اجرا کنید.

ارتفاع سفید ۱۸۰، سیاه ۱۳۰ و ربع‌پرده ۹۷٫۵ و عرض سیاه/ربع‌پرده ۴۰ است. رنگ مات سُری `#777777` و کُرُن `#bdbdbd` معادل ظاهر قبلی روی سفید است و مرز سفیدها را می‌پوشاند. نمایش خودکار گام ایرانی، فرکانس ربع‌پرده‌ها، برچسب‌ها، راهنما، نگه‌داشتن برای انتخاب کشش و عملکرد ابزارها حفظ شده‌اند.

## فایل‌ها و ترتیب انتشار

۱. ابتدا فایل تازهٔ `assets/notation/piano_style.js` و سپس `assets/notation/ui_controls.css`.

۲. `assets/notation/notation.js` و در پایان `assets/notation/index.html`. بارگذاری وابستگی‌های صفحه از همان روش نسخه‌بندی فعلی PHP استفاده می‌کند. اگر HTML کش‌شده هنوز script تازه را نداشته باشد، ویرایشگر فایل تولیدی را پیش از راه‌اندازی بارگذاری می‌کند.

۳. روی سرور تست، نت ماژور و شور را باز کنید؛ ارتفاع هر سه نوع و خاکستری متفاوت سری/کرن، کلیک برای ورود، کشیدن برای کشش نقطه‌دار، ذخیره/بازگشایی و عرض موبایل را بررسی کنید. با کاربر دیگر، منع ویرایش نت خصوصی را از مسیر موجود بررسی کنید.

کلاس PHP، API یا migration تازه‌ای وجود ندارد. فایل‌های سازگار نت‌نویسی/Bravura مرحلهٔ قبل باید حاضر باشند. برای بازگشت، نسخهٔ سازگار قبلی `notation.js`، CSS و HTML را برگردانید؛ باقی‌ماندن فایل تولیدی جدید اثری روی داده‌ها ندارد. دادهٔ نت و API مرحلهٔ قبل را حفظ کنید. انتشار روی سرور اصلی و آزمون دستگاه فیزیکی انجام نشده است.

نتیجهٔ آزمون کامل در `storage/logs/shared-piano-release.log`: ۱۴۱ از ۱۴۳ مجموعه موفق. دو شکست قدیمی مربوط به فایل مفقود `scripts/music-practice-integration-test.php` و آزمون مرورگر وابسته‌اند؛ آزمون‌های نت‌نویسی موفق‌اند. ۲۴ اجرای رفتار با فایل‌های واقعی وب و چهار اجرای تعامل/چیدمان وب، به‌علاوهٔ آزمون‌های معادل اپ، موفق‌اند. خروجی مشترک با `--check`، نحو JavaScript و `git diff --check` نیز بررسی شدند.
