# 1. Vision

Sornaz is a modern educational management platform designed to manage educational organizations of different sizes.

The platform is built around flexibility, scalability and simplicity.

Its architecture supports:

- Single academy
- Multi-branch organizations
- Multi-language
- Multi-user
- Permission-based access
- Cloud deployment
- Self-hosted deployment

The goal is to become a complete educational ERP rather than only a student management system.
