# لینک هدر و دسترسی نت‌نویسی وب

مجوز `notation.access` نمایش لینک نت‌نویسی در هدر دسکتاپ و موبایل و دسترسی به `/music-sheets` و API نشست وب را کنترل می‌کند. مدیر اصلی با شناسه ۱ همواره مجاز است. migration هیچ مجوزی به نقش‌ها یا کاربران فعلی نمی‌دهد؛ مدیر سایت از پنل کاربران و دسترسی‌های کاربر، مجوز «دسترسی به نت‌نویسی وبسایت» را واگذار یا لغو می‌کند. قواعد مالکیت نت، CSRF و بررسی حساب عوض نشده‌اند. API دارای bearer اپلیکیشن مستقل از این محدودیت وب باقی می‌ماند. OMR همچنان مخصوص مدیر اصلی است.

در عرض حداکثر ۷۰۰ پیکسل، دستگاه لمسی یا حالت standalone مربوط به PWA، پوسته فشرده فعال می‌شود: ویرایشگر، پیانو، ابزارهای نت و دیالوگ‌ها از پیاده‌سازی مشترک استفاده می‌کنند. نوار ابزار ۴۸ پیکسلی با آیکن‌های ۲۲ پیکسلی و فاصله ۴ پیکسل، ترتیب دکمه‌های فلاتر را دارد. پوسته دسکتاپ پنل روی موبایل غیرفعال است و تغییر اندازه، نت ذخیره‌نشده را حفظ می‌کند. فایل‌های پروژه فلاتر تغییر نکرده‌اند. ذخیره فایل و چاپ از امکانات مرورگر استفاده می‌کنند؛ محدودیت‌های سیستم‌عامل مرورگر همچنان برقرارند.

## انتشار

ابتدا migration زیر را با نسخه پشتیبان روی دیتابیس تست اجرا کنید، سپس اجرای مجدد آن را بررسی کنید. این migration فقط کاتالوگ مجوز و ترجمه‌های مفقود را اضافه می‌کند و ترجمه موجود را بازنویسی نمی‌کند:

- `docs/database/migrations/2026_11_14_notation_website_access.sql`

فایل‌های قابل بارگذاری، ابتدا دارایی‌ها و سپس PHP؛ انتقال اتمی ترجیح دارد:

- `assets/notation/responsive_host.js`
- `assets/notation/mobile_host.css`
- `assets/notation/notation.js`
- `Modules/System/Services/AccessControl.php`
- `Modules/Notation/Controllers/NotationController.php`
- `Modules/Notation/Resources/Views/index.php`
- `Modules/Page/Resources/Views/sections/main-header.php`
- `Modules/Analytics/Resources/Views/sections/main-header.php`
- `Modules/Home/Resources/Views/partials/header.php`
- `Modules/Analytics/Resources/Views/sections/notation.php`

در فهرست نت‌های موبایل و PWA، دکمه‌های واردکردن نت و تشخیص نت از تصویر نمایش داده نمی‌شوند؛ این قاعده هم در صفحه مستقل و هم نوار بیرونی پنل اعمال می‌شود.

جستجو و تنها دکمه تنظیمات با آیکن چرخ‌دنده در ردیفی بالای تب‌های فهرست موبایل/PWA قرار دارند؛ نوار بیرونی تکراری پنل در این حالت مخفی است. لینک نت‌نویسی در هدرها بلافاصله بعد از آموزشگاه‌ها قرار می‌گیرد.

نسخه جدید AccessControl باید پیش از کنترلر و هدرها حاضر باشد. پیش از migration، دسترسی مدیر اصلی برقرار است و دیگران مجاز نیستند. کلاس و وابستگی جدید وجود ندارد. نسخه‌گذاری دارایی‌های نت‌نویسی بر پایه زمان تغییر فایل باقی مانده است. برای بازگشت، این فایل‌ها را با هم از نسخه قبل بازیابی کنید؛ رکورد مجوز می‌تواند بدون استفاده باقی بماند و داده نت‌ها پاک نشود. بازگشت کنترلر به نسخه قبل، محدودیت دسترسی وب را نیز برمی‌دارد.

پس از انتقال، با مدیر اصلی لینک هدر و ویرایش را بررسی کنید؛ با کاربر عادی لینک نباید دیده شود و مسیر مستقیم و API باید ۴۰۳ بدهند. مجوز را به همان کاربر بدهید، صفحه را تازه کنید و دسترسی را بررسی کنید؛ پس از لغو دوباره ۴۰۳ دریافت شود. یک نت خصوصی کاربر دیگر همچنان غیرقابل دسترس باشد. موبایل و PWA را در فارسی/انگلیسی، پخش، انتخاب نت، درج سکوت، حفظ نت پس از تغییر اندازه و چاپ بررسی کنید.

آزمون‌های محلی fixture جای اجرای migration و آزمون دیتابیس واقعی یا نصب PWA روی دستگاه را نمی‌گیرند. migration و انتشار اصلی خودکار انجام نشده‌اند.

## آزمون‌های این تغییر

- `php scripts/notation_header_access_test.php`: هدرهای دسکتاپ/موبایل، مهمان، مدیر اصلی، کاربر عادی، واگذاری و لغو مجوز موفق.
- `php scripts/notation_web_account_test.php`: مجوز وب، حساب نشست، رد تب قدیمی و مجوز لغوشده موفق.
- `node scripts/notation_mobile_host_test.cjs`: فارسی/انگلیسی در موبایل و شبیه‌سازی standalone، ابعاد نوار، جای پیانو، دیالوگ کشش، درج سکوت و حفظ JSON نت ذخیره‌نشده پس از تغییر اندازه موفق.
- `node scripts/notation_menu_browser_test.cjs` و `node scripts/notation_web_parity_browser_test.cjs`: منوها، واردکردن نت، ذخیره، آپلود، لیست، دانلود و بازخوانی آفلاین موفق. جدول/کارت مخصوص دسکتاپ است؛ موبایل فهرست مشترک دارد.
- نحو فایل‌های PHP/JavaScript تغییرکرده و `git diff --check` موفق.

بررسی عمومی `php scripts/php-maintainability.php check` به علت محدودیت‌های حجم متد در فایل‌های موجود دیگر و متد قدیمی اعتبارسنجی نت موفق نیست؛ این اصلاح اندازه آن متدها را تغییر نداده است. نتیجه کامل آزمون انتشار باید همراه با شکست‌های قبلی بررسی شود و موفقیت آزمون‌های فوق به معنی تأیید انتشار اصلی یا اجرای migration نیست.

در اجرای کامل، آزمون‌های منو و web parity ابتدا انتظار جدول دسکتاپ در موبایل داشتند؛ با قرارداد جدید فهرست موبایل اصلاح و جداگانه موفق اجرا شدند. موارد باقیمانده مربوط به فایل مفقود `music-practice-integration-test.php` و آزمون مرورگر وابسته به آن، انتظار قدیمی مخفی‌بودن نت‌نویسی در sidebar، انتخابگرهای قدیمی کلید حامل/واحد ضرب و انتظار قبلی شاهین‌گذاری در fixture مشترک هستند. این آزمون‌های خارج از تغییر حاضر بازنویسی نشده‌اند.
