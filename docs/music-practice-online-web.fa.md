# اجرای آنلاین آزمون‌ها در وب

وب برای فهرست و مدیریت آزمون‌ها به کلید آفلاین وابسته نیست. مسیرهای `/exams/api/…` برای نوشتن، احراز هویت نشست و CSRF را حفظ می‌کنند. هنگام ثبت نتیجه، دسترسی فعلی کاربر و نسخهٔ فعلی آزمون در سرور بررسی می‌شود؛ انتخاب حالت آنلاین از payload پذیرفته نمی‌شود.

API موبایل `/api/sornaz/v1/music-practice/…` همچنان مجوز امضاشدهٔ آفلاین را الزامی می‌داند. برای اجرای آفلاین Flutter، مقدار پایدار `MUSIC_PRACTICE_SIGNING_KEY` با حداقل ۳۲ نویسه روی سرور لازم است. این تغییر، کلید یا قرارداد مجوز موبایل را عوض نمی‌کند.

دکمه‌های به‌روزرسانی و بارگذاری نتایج ذخیره‌شده از وب حذف شده‌اند. دریافت فهرست و ارسال پاسخ‌ها خودکار است؛ خطای سرور با پیام نمایش نسخهٔ آفلاین پوشانده نمی‌شود. ثبت محلی پاسخ برای تلاش مجدد خودکار در قطع موقت درخواست باقی مانده، اما شروع آزمون و ثبت پاسخ در حالت آفلاین مرورگر مجاز نیست. Flutter در این تغییر ویرایش نشده است.

مقاله و آزمون‌ها از `resources/views/partials/breadcrumb.php` استفاده می‌کنند. آرایهٔ `$breadcrumbItems` شامل `label` و در صورت نیاز `href` داخلی معتبر است. آیتم بدون href صفحهٔ جاری است. برچسب‌ها escape می‌شوند. مسیر پویا از قالب‌های DOM همان partial استفاده می‌کند؛ بردکرامب بالای عنوان آزمون قرار دارد.

## انتشار و بازگشت

Migration یا وابستگی تازه لازم نیست. ترتیب دقیق فایل‌های قابل آپلود:

۱. `resources/views/partials/breadcrumb.php` و سپس `Modules/Education/Services/MusicPracticeStore.php`.

۲. سرویس‌ها و کنترلر:

- `Modules/Education/Services/MusicPracticeCatalog.php`
- `Modules/Education/Services/MusicPracticeResults.php`
- `Modules/Education/Controllers/MusicPracticeController.php`

۳. `assets/Education/js/music-practice.js` و سپس دو view:

- `Modules/Education/Resources/Views/music-practice.php`
- `Modules/Analytics/Resources/Views/article-details.php`

نسخهٔ JS با AssetManager عوض می‌شود. OPcache را طبق روش میزبان تازه کنید؛ پس از انتشار کامل، صفحه‌های از قبل باز را تازه کنید تا رابط قبلی وابسته به مجوز آفلاین باقی نماند. تنظیمات، کلیدها و داده‌های کاربران را جایگزین نکنید.

برای بازگشت، همین مجموعهٔ PHP، JS و view را هماهنگ به نسخهٔ پیشین برگردانید؛ partial را فقط پس از برگشت viewها حذف کنید. دیتابیس تغییر نمی‌کند. نسخهٔ پیشین دوباره به کلید آفلاین معتبر نیاز خواهد داشت.

پس از آپلود، مدیریت و ویرایش آزمایشی یک آزمون با مدیر، رد دسترسی کاربر فاقد مجوز، اجرای آزمون رایگان و ثبت نتیجه را بررسی کنید. بردکرامب مقاله و آزمون در فارسی/انگلیسی و موبایل بررسی شود. API موبایل باید نتیجه با امضای نامعتبر را همچنان رد کند.

## آزمون

`node scripts/music-practice-online-test.cjs` سرویس‌های واقعی را روی SQLite حافظه‌ای، بدون خواندن تنظیمات دیتابیس اصلی می‌آزماید: نبود کلید، مدیریت، ذخیره و درخواست تکراری نتیجه، لغو دسترسی، نسخهٔ قدیمی و جدایی مجوز موبایل. آزمون مرورگر با HTTP شبیه‌سازی‌شده، قالب مشترک، ناوبری، حذف دکمه‌ها و خطای سرور را در فارسی/انگلیسی و موبایل/دسکتاپ بررسی می‌کند. این آزمون جای آزمون سرور اصلی نیست.
