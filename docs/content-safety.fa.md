# امنیت ورودی و نمایش محتوا

## تغییرات این مرحله

۱. کلاس `Core\security\ContentSafety` سیاست مشترک متن ساده، HTML، URL و JSON داخل اسکریپت را فراهم می‌کند.
۲. مقاله و دیدگاه در زمان ثبت و نمایش پاک‌سازی می‌شوند؛ محتوای قدیمی دیتابیس و ترجمهٔ انگلیسی API نیز هنگام خواندن محافظت می‌شوند.
۳. پاک‌سازی HTML با نسخهٔ رسمی HTML Purifier 4.19.1 انجام می‌شود. دیدگاه‌ها فقط قالب‌بندی متن و لینک دارند. مقاله علاوه بر آن تصویر و جدول دارد. اسکریپت، رویدادهای HTML، فرم، iframe، SVG و CSS دلخواه حذف می‌شوند؛ قالب‌بندی وابسته به این موارد ممکن است تغییر کند.
۴. درج لینک در ویرایشگر دیدگاه با ساخت عنصر DOM انجام می‌شود و فقط HTTP/HTTPS پذیرفته می‌شود. دادهٔ مقاله در اسکریپت با رمزگذاری مخصوص JSON درج می‌شود.
۵. محتوای ویرایش صفحات قبل از نوشتن اعتبارسنجی می‌شود: تطابق صفحه و نوع با کلید، اعتبار URL تصویر، کلاس آیکن و متن هر دو زبان. ذخیره در تراکنش انجام می‌شود.
۶. متن ساده مانند گفتگو باید به همان صورت ذخیره و متناسب با محل نمایش escape شود؛ نباید برای همهٔ متن‌ها از حذف تگ استفاده کرد. تابع عمومی `e()` اکنون UTF-8 نامعتبر را جایگزین می‌کند.

## انتشار

- فایل‌های اصلاح‌شده، کلاس جدید و **تمام پوشهٔ `Modules/System/Lib/HTMLPurifier`** را با هم آپلود کنید.
- فایل‌های autoload تولیدشده را منتقل کنید یا روی سرور `composer dump-autoload --no-scripts --no-plugins` اجرا کنید. بزرگی و کوچکی نام پوشه‌ها حفظ شود.
- این مرحله SQL جدید ندارد؛ محتوای قدیمی به صورت انبوه بازنویسی نشده است.
- پس از انتشار، مقاله و دیدگاه فارسی و انگلیسی، ویرایش متن صفحه و ثبت نظر را بررسی کنید.
- تست‌ها در محیط مستقل اجرا می‌شوند؛ دیتابیس و سرور اصلی تغییر نکرده‌اند.

## آزمون و حدود پوشش

`php scripts/content_safety_test.php` ورودی مخرب، طرح URL، UTF-8، محدودیت طول، حفظ قالب‌بندی و مسیر واقعی ذخیره و خواندن دیدگاه قدیمی را بررسی می‌کند. این آزمون در مجموعهٔ انتشار نیز قرار دارد.

این مرحله مسیرهای مقاله، دیدگاه و ویرایش محتوای صفحات را متمرکز می‌کند. به معنی پوشش تمام sinkهای HTML در همهٔ بخش‌های قدیمی پنل نیست؛ برای توسعهٔ بعدی استفاده از `innerHTML` و خروجی خام PHP باید به‌صورت موردی بررسی شود. همچنین محدودیت نرخ، سطح دسترسی و امنیت آپلود جایگزین پاک‌سازی محتوا نیستند و سیاست‌های مستقل خود را دارند.
