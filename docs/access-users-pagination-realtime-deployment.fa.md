# جدول نقش‌ها و دسترسی‌ها

## فایل‌های انتشار

1. `assets/Analytics/js/admin-ui-templates.js`
2. `assets/Analytics/js/users.js`
3. `assets/Analytics/js/teachers.js`
4. `Modules/Analytics/Resources/Views/sections/panel-table-template.php`
5. `Modules/Analytics/Resources/Views/sections/users.php`

ابتدا JavaScript مشترک، سپس فایل کاربران و کارمندها، بعد قالب مشترک و در پایان قالب کاربران را منتشر کنید. کش مرورگر/CDN را تازه کنید تا قالب جدید با اسکریپت قدیمی اجرا نشود. کلاس یا migration جدید لازم نیست. انتشار روی سرور اصلی انجام نشده است.

جدول نقش‌ها و دسترسی‌ها از قاب و سطرهای قالب عمومی و تابع مشترک `AdminPanelTable.renderPagination` استفاده می‌کند. صفحه‌بندی همچنان سمت سرور است تا محدوده آموزشگاه/شعبه، جست‌وجو، وضعیت و مرتب‌سازی کل فهرست حفظ شود. هر صفحه ۱۰ کاربر دارد؛ نوار صفحه‌بندی برای حداکثر ۱۰ کاربر مخفی است. قالب جدول امتیازهای شخصی هم همین تابع صفحه‌بندی را فراخوانی می‌کند.

پس از دریافت دوباره اطلاعات قراردادها، رویداد `staff:data-updated` منتشر می‌شود و فهرست نقش‌ها و دسترسی‌ها با همان فیلترها از سرور تازه می‌شود. برای نشان دادن کارمند تازه، صفحه اول بارگذاری می‌شود. همگام‌سازی فعلی قراردادها بین پنجره‌ها و بررسی نسخه قراردادها نیز همین رویداد را فعال می‌کنند. هیچ سطر یا مجوزی از داده فرم به جدول کاربران تزریق نمی‌شود؛ داده معتبر از API مجاز فعلی خوانده می‌شود. پاسخ دیررس درخواست قبلی نتیجه جدید را بازنویسی نمی‌کند.

## آزمون و بازگشت

آزمون `node scripts/access_users_realtime_browser_test.cjs` ذخیره قرارداد از handler واقعی مرورگر با API آزمایشی، نمایش فوری سطر جدید، حفظ فیلتر و کنار گذاشتن پاسخ قدیمی را بررسی می‌کند. این آزمون ثبت قرارداد واقعی روی دیتابیس اصلی انجام نمی‌دهد. `node scripts/panel_table_browser_test.cjs` مرتب‌سازی سراسری و صفحه دوم با ۱۰ ردیف را بررسی می‌کند. `node scripts/personal_points_pagination_browser_test.cjs` سازگاری مصرف‌کننده دیگر صفحه‌بندی مشترک را می‌سنجد.

پس از آپلود روی محیط تست، با حساب آموزشگاه قرارداد آزمایشی ثبت کنید و بدون رفرش وارد تب نقش‌ها و دسترسی‌ها شوید. کارمند تازه باید با رعایت فیلتر فعال دیده شود. فیلتر شعبه، صفحه بعد و مرتب‌سازی شناسه را بررسی کنید. حساب آموزشگاه دیگر نباید کارمند تازه را ببیند. داده آزمایشی را با روش معمول پنل پاک کنید.

برای بازگشت پنج فایل را هماهنگ به نسخه قبل برگردانید و کش را تازه کنید. داده و ساختار دیتابیس تغییر نکرده‌اند.
