# توقف ایمیل کد فعال‌سازی نسخهٔ قدیمی dansim.ir

این بسته فقط برای پروژهٔ قدیمی `sornaz----old` است؛ در پروژهٔ جدید سرناز آپلود نشود.

## فایل قابل آپلود

فقط `system/services/mailer.php` را در همان مسیر نسبت به ریشهٔ سایت `dansim.ir` جایگزین کنید. فایل ZIP همراه نیز فقط همین فایل را دارد. README و tests برای اجرا روی سایت لازم نیستند. هیچ فایل تنظیمات، رمز، نشست یا دیتابیس در بسته نیست.

## رفتار

`Mailer::sendOtp()` برای purpose برابر `register` پیش از ساخت پیام و اتصال SMTP مقدار `false` برمی‌گرداند. این توقف برای همهٔ گیرندگان و درخواست‌های تکراری اعمال می‌شود. کد یا وضعیت تأیید حساب تغییر نمی‌کند و تأیید دور زده نمی‌شود. مسیرهای قدیمی که نیازمند دریافت این ایمیل هستند، با توقف ارسال نمی‌توانند تأیید ایمیلی را تکمیل کنند؛ بعضی کنترلرهای قدیمی ممکن است همچنان پیام «ارسال شد» نشان دهند، زیرا نتیجهٔ ارسال را بررسی نمی‌کنند.

ایمیل کد ورود، بازیابی رمز، لینک تأیید و پیامک‌ها با این تغییر غیرفعال نمی‌شوند. کلاس، وابستگی و migration جدیدی وجود ندارد.

## انتشار و بازگشت

1. از فایل فعلی `system/services/mailer.php` روی هاست در محلی خصوصی و خارج از ریشهٔ وب پشتیبان بگیرید.
2. فایل بسته را ابتدا با نام موقت خارج از دسترس عمومی بارگذاری و سپس به‌صورت اتمی جایگزین کنید تا فایل نیمه‌آپلودشده در درخواست‌های جاری خوانده نشود. فقط یک فایل تغییر کرده است و ترتیب وابسته به فایل دیگر یا دیتابیس وجود ندارد.
3. اگر OPcache تغییر فایل را خودکار تشخیص نمی‌دهد، از روش معمول هاست برای تازه‌سازی آن استفاده کنید. درخواست SMTP که پیش از جایگزینی شروع شده باشد با این تغییر لغو نمی‌شود.
4. برای بازگشت، فقط نسخهٔ پشتیبان همان فایل را به‌صورت اتمی بازگردانید؛ با بازگشت، ارسال این ایمیل دوباره فعال می‌شود.

## آزمون

آزمون محلی با SMTP ساختگی، توقف ارسال ثبت‌نام و درخواست تکراری، و حفظ ارسال کد ورود/بازیابی و لینک‌های تأیید/بازیابی را بررسی می‌کند؛ ارسال واقعی ایمیل یا تغییر دادهٔ واقعی انجام نمی‌دهد:

```sh
php -l system/services/mailer.php
php tests/mail-policy.php
```

پس از آپلود، از مسیر ریشهٔ سایت در CLI هاست دستور زیر را اجرا کنید؛ خروجی باید `disabled` باشد و هیچ ایمیلی ارسال نمی‌کند:

```sh
php -r 'require "system/services/mailer.php"; if (Mailer::sendOtp("recipient@example.test", "000000", "register") !== false) { exit(1); } echo "disabled\n";'
```

سپس صفحهٔ اصلی و ورود سایت و یک مسیر خصوصی با کاربر مهمان را بررسی کنید: سایت باید باز شود و مسیر خصوصی همچنان ورود بخواهد یا دسترسی را رد کند. آزمون میزبان و SMTP واقعی در این کار انجام نشده است.
