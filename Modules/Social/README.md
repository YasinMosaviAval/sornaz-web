# API اجتماعی موبایل

مسیر /api/sornaz/v1/social با Bearer token موجود موبایل: پروفایل، فالو، پست، استوری ۲۴ساعته، لایک، نشان‌کردن، اعلان داخلی و دایرکت. فایل‌ها در storage/social-media هستند و دسترسی مستقیم باید در وب‌سرور ممنوع باشد. تنظیم Apache همراه ماژول است؛ در Nginx قانون deny معادل لازم است.

نصب: php Modules/Social/install.php (جداول دوره نیز آماده می‌شوند). سورس نصب هر دو ماژول در `install.php.example` قرار دارد؛ آماده‌سازی فایل اجرایی روی سرور لازم است، چون مسیر `install.php` در محیط فعلی خطای دسترسی ویندوز دارد. جداول محلی نصب شده‌اند.

دایرکت از ChatService سایت استفاده می‌کند. اعلان Push سیستم‌عامل، نظرات، گزارش/بلاک، تسویه مدرس و ارسال پیوست جدید چت در این نسخه اضافه نشده‌اند. دوره‌ها به CourseMarket وصل‌اند و درس‌ها posts خصوصی هستند.

محدودیت‌ها: ۳۰ پست در هر صفحه؛ کاربران و فالوورها حداکثر ۵۰ مورد، اعلان‌ها حداکثر ۱۰۰ مورد؛ سقف رسانه حساب ۲ گیگابایت. استوری پس از ۲۴ ساعت از API حذف می‌شود؛ پاک‌سازی فیزیکی فایل‌های بلااستفاده هنوز خودکار نیست.

صفحات خانه و حساب از `/home` و `/dashboard` داده می‌گیرند. `/bookmarks` برای ذخیره دوره و نویسنده، `/settings` برای تنظیمات اعلان و لینک‌های عمومی، و `/courses/{id}/lessons/{postId}/progress` برای تکمیل درس است. تغییرات فقط با Bearer token معتبر پذیرفته می‌شوند. خانه، پروفایل، پست عمومی، فهرست دوره و تصویر جلد بدون ورود قابل مشاهده‌اند؛ فایل درس همچنان نیازمند خرید و مجوز رمز است.

برای ارتقای نصب موجود، `profile-schema.sql` را در همان دیتابیس اجرا کنید. این فایل فقط سه جدول جدید می‌سازد و داده‌های قبلی را تغییر نمی‌دهد. روی دیتابیس محلی اجرا شده است.

پیشرفت با علامت‌گذاری صریح «این درس را تکمیل کردم» ثبت می‌شود؛ دستاوردها از شمارش واقعی درس‌ها و دوره‌های تکمیل‌شده محاسبه می‌شوند. تنظیمات خاموش‌کردن اعلان روی اعلان‌های جدید اثر دارند. دانلودها در حافظه خصوصی اپ و جداگانه برای هر حساب هستند؛ بازکردنشان به تأیید آنلاین خرید و رمز فعلی نیاز دارد.

اعتبارسنجی جدید: ۲۲ بررسی یکپارچه در جدول‌های موقت با `php Modules/Social/profile-check.php.example`. پرداخت واقعی و آزمون روی گوشی فیزیکی انجام نشده است.
