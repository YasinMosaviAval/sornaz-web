# API اجتماعی موبایل

مسیر /api/sornaz/v1/social با Bearer token موجود موبایل: پروفایل، فالو، پست، استوری ۲۴ساعته، لایک، نشان‌کردن، اعلان داخلی و دایرکت. فایل‌ها در storage/social-media هستند و دسترسی مستقیم باید در وب‌سرور ممنوع باشد. تنظیم Apache همراه ماژول است؛ در Nginx قانون deny معادل لازم است.

نصب: php Modules/Social/install.php (جداول دوره نیز آماده می‌شوند). سورس نصب هر دو ماژول در `install.php.example` قرار دارد؛ آماده‌سازی فایل اجرایی روی سرور لازم است، چون مسیر `install.php` در محیط فعلی خطای دسترسی ویندوز دارد. جداول محلی نصب شده‌اند.

دایرکت از ChatService سایت استفاده می‌کند. نظرات پست‌ها و پاسخ خصوصی استوری در سایت و API مشترک پیاده‌سازی شده‌اند. اعلان Push سیستم‌عامل، گزارش/بلاک، تسویه مدرس و ارسال پیوست جدید چت در این نسخه اضافه نشده‌اند. دوره‌ها به CourseMarket وصل‌اند و درس‌ها posts خصوصی هستند.

محدودیت‌ها: ۳۰ پست در هر صفحه؛ کاربران و فالوورها حداکثر ۵۰ مورد، اعلان‌ها حداکثر ۱۰۰ مورد؛ سقف رسانه حساب ۲ گیگابایت. استوری پس از ۲۴ ساعت از API حذف می‌شود؛ پاک‌سازی فیزیکی فایل‌های بلااستفاده هنوز خودکار نیست.

صفحات خانه و حساب از `/home` و `/dashboard` داده می‌گیرند. `/bookmarks` برای ذخیره دوره و نویسنده، `/settings` برای تنظیمات اعلان و لینک‌های عمومی، و `/courses/{id}/lessons/{postId}/progress` برای تکمیل درس است. تغییرات فقط با Bearer token معتبر پذیرفته می‌شوند. خانه، پروفایل، پست عمومی، فهرست دوره و تصویر جلد بدون ورود قابل مشاهده‌اند؛ فایل درس همچنان نیازمند خرید و مجوز رمز است.

برای ارتقای نصب موجود، `profile-schema.sql` را در همان دیتابیس اجرا کنید. این فایل فقط سه جدول جدید می‌سازد و داده‌های قبلی را تغییر نمی‌دهد. روی دیتابیس محلی اجرا شده است.

پیشرفت با علامت‌گذاری صریح «این درس را تکمیل کردم» ثبت می‌شود؛ دستاوردها از شمارش واقعی درس‌ها و دوره‌های تکمیل‌شده محاسبه می‌شوند. تنظیمات خاموش‌کردن اعلان روی اعلان‌های جدید اثر دارند. دانلودها در حافظه خصوصی اپ و جداگانه برای هر حساب هستند؛ بازکردنشان به تأیید آنلاین خرید و رمز فعلی نیاز دارد.

اعتبارسنجی جدید: ۲۲ بررسی یکپارچه در جدول‌های موقت با `php Modules/Social/profile-check.php.example`. پرداخت واقعی و آزمون روی گوشی فیزیکی انجام نشده است.

## جامعه در وب

مسیر `/community` رابط واکنش‌گرای فارسی/انگلیسی با فید، استوری، دایرکت، اعلان‌ها، صفحهٔ نظرهای پست، انتشار پست/استوری، ذخیره‌ها و پروفایل دارد. لینک ورود به این بخش در سربرگ و پابرگ سایت قرار دارد. مسیرهای `/community/posts/{id}`، `/community/stories/{id}` و `/community/direct/{id}` قابل بازکردن مستقیم‌اند.

API وب در `/community/api` فقط از نشست سایت و برای تمام تغییرات از هدر CSRF استفاده می‌کند. مسیر API موبایل همچنان فقط Bearer می‌پذیرد. بازدید پست‌های عمومی و نظرها برای مهمان مجاز است، ولی ارسال، پاسخ و دایرکت ورود لازم دارند. کامنت را نویسندهٔ آن یا صاحب پست می‌تواند حذف کند. دسترسی دایرکت توسط عضویت ChatService کنترل می‌شود.

ارسال پست به یک تا ده عضو، لینک معتبر همان پست را در گفت‌وگوی خصوصی ذخیره می‌کند. پاسخ استوری و شش واکنش ❤️ 😂 😍 😮 😢 👏 نیز خصوصی‌اند؛ استوری منقضی‌شده پاسخ نمی‌پذیرد. استوری‌ها بر اساس نویسنده گروه‌بندی می‌شوند، تصویر و ویدیو تمام کادرند، سربرگ روی رسانه قرار دارد و سویپ بالا پنل پاسخ/واکنش را باز می‌کند. ویدیوی طولانی در نوار پیشرفت به قطعات ۶۰ ثانیه‌ای تقسیم می‌شود و هنگام بازبودن پاسخ یا مخفی‌شدن صفحه مکث می‌کند.

دریافت خودکار دوره‌ای وجود ندارد. خواندن‌های یکسان مشترک و تا یک دقیقه در حافظهٔ همان صفحه نگهداری می‌شوند؛ خطای ارتباط یا محدودیت سرور درخواست‌ها را موقتاً متوقف می‌کند. بارگذاری بیشتر و تازه‌سازی صریح‌اند. رسانه فقط از مبدأ همان سایت پذیرفته می‌شود و متن کاربر به HTML تبدیل نمی‌شود.

ارتقای دیتابیس: `php Modules/Social/comments-upgrade.php.example` جدول جدید `social_comments` را بدون تغییر داده‌های قبلی می‌سازد. اجرا روی دیتابیس محلی انجام شده است؛ هنگام انتشار روی سرور باید همین ارتقا اجرا شود (برای میزبان دیتابیس غیرمحلی، پارامتر صریح `--allow-remote` لازم است).

اعتبارسنجی:

- `php Modules/Social/interactions-check.php.example`: مجوز، CSRF، جداسازی کوکی از Bearer، صفحه‌بندی نظرها، ارسال خصوصی و انقضای استوری؛ همه در جدول‌های موقت اتصال محلی.
- `node scripts/social_web_test.cjs`: مرورگر فارسی/انگلیسی، عرض موبایل/دسکتاپ، ارسال، کامنت، استوری و سویپ، مهمان، فراردهی HTML و توقف درخواست پس از محدودیت سرور. همهٔ HTTPها شبیه‌سازی می‌شوند؛ هیچ پیام واقعی ارسال نمی‌شود.
